# Marcha Atrás en Cambio de Sentido — Prohibida

## Pregunta de examen (errada)

> El conductor da marcha atrás para finalizar el cambio de sentido, ¿es correcto?

**Respuesta dada (ERRADA):** B) Sí, cuando no sea obstáculo para otros vehículos.

## Respuesta correcta

**VERDAD.** **No, en esta maniobra no se debe utilizar la marcha hacia atrás.**

## Explicación detallada

### Regla del cambio de sentido

- El cambio de sentido se hace en **una sola maniobra**
- **NO se puede usar marcha atrás** para completar el cambio
- Si no se consigue en una maniobra, hay que **reiniciar** el proceso

### ¿Por qué está prohibido?

| Riesgo | Consecuencia |
|--------|-------------|
| Visibilidad reducida | No se ve bien detrás al dar marcha atrás |
| Ocupación del carril contrario | Se queda bloqueado en el carril de enfrente |
| Confusión | Otros conductores no esperan marcha atrás en esta maniobra |

### Proceso correcto del cambio de sentido

1. **Señalizar** con intermitente izquierdo
2. **Reducir velocidad** y comprobar seguridad
3. **Girar** a la izquierda cruzando el carril contrario
4. **Completar** el giro en una sola maniobra
5. Si no se consigue → **reiniciar**, NO dar marcha atrás

### Errores habituales

| Error | Consecuencia |
|-------|-------------|
| Usar marcha atrás para ajustar posición | Multa + peligro de colisión |
| Pensar que es aceptable si no hay obstáculos | Regla absoluta, sin excepciones |
| No señalar antes de iniciar | Multa por falta de señalización |

## Recordatorio

**Cambio de sentido = maniobra continua.** Marcha atrás = PROHIBIDA. Si no sale, se repite desde el inicio.
