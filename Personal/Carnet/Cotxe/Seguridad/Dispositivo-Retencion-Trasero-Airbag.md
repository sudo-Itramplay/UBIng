# Dispositivo de retención orientado hacia atrás — Precaución con el airbag

## Pregunta de examen (errada)

> 11. ¿Qué precaución debe adoptar si instala un dispositivo de retención orientado hacia atrás?

**Respuesta dada (ERRADA):** C — "No se puede instalar el dispositivo si el vehículo está equipado con airbag frontal."

## Respuesta correcta

**VERDAD.** Se **puede instalar**, pero hay que **desactivar el airbag frontal** de forma automática o manual.

## Explicación detallada

### Dispositivo de retención orientado hacia atrás (silla bebe)

- Un **dispositivo de retención infantil orientado hacia atrás** (silla de bebé) es aquel donde el niño mira hacia la parte trasera del coche.
- Si se instala en el **asiento delantero** y el airbag frontal está **activado**, el airbag puede golpear al niño con fuerza mortal al desplegarse.

### ¿Qué hacer?

| Situación | Acción |
|-----------|--------|
| Airbag frontal **automático** | Se desactiva **automáticamente** al colocar el SRI |
| Airbag frontal **manual** | Se debe desactivar **manualmente** antes de instalar el SRI |
| Airbag frontal **no se puede desactivar** | **NO se puede instalar** el SRI en el asiento delantero |

### Clave

- **SÍ se puede instalar** → solo hay que desactivar el airbag.
- **NO se puede instalar** → solo si el airbag NO se puede desactivar.
- La opción "no se puede instalar" es falsa como afirmación general. Solo es cierta en el caso específico de que el airbag sea indestructible.

### Errores habituales

| Error | Peligro |
|-------|---------|
| Creer que nunca se puede instalar con airbag | Restringe innecesariamente el uso del SRI |
| Instalar sin desactivar el airbag | El airbag puede matar al niño |

## Recordatorio

**SÍ se puede instalar → solo desactivar el airbag.** No prohibido, condicionado.
