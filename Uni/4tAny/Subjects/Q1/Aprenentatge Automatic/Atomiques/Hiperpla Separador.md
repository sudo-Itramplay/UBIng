# Hiperpla Separador

- Un **hiperpla separador** és un hiperpla $f(X) = 0$ que separa **perfectament** les dues classes:
$$Y_i \cdot f(X_i) > 0 \quad \forall i$$
- $f(X) > 0$ a un costat, $f(X) < 0$ a l'altre; les classes es codifiquen com $Y_i = +1$ / $Y_i = -1$.
- Entre tots els hiperplans separadors, el **classificador de marge màxim** n'escull el **millor**: el que té el forat més gran entre classes → veure [[ML5 — SVM]].
