# Pull system

**Referència: [[KANBAN]] Diapositives 18-20**

Model de flux on l'equip **pulla** feina en lloc que se li **empenti**.

- **Empènyer (push)**: fàcil generar **fricció** entre equips, especialment quan un és més performant i empeny més feina de la que l'altre pot **realment manejar**.
- **Pullar**: un equip pulla feina quan **està llest** per a ella.
- Cada cop que algú **pulla un item**, **identifica l'ownership** de les tasques (a qui li toca).

Amb **cues** al tauler (entre equips interdependents):

- L'equip **més lent** pot **bloquejar tot el procés**.
- Com que el sistema és pull, una **lane bloquejada** = l'equip responsable **no pot pullar res nou** fins que l'equip bloquejant pulli un item.
- Per això s'afegeixen **cues** al tauler, amb **capacitat màxima** pròpia.

> [!tip] Relació amb [[WIP|els límits de WIP]]: el límit de columna **força** el pull — si la columna és plena, no pots pullar.
