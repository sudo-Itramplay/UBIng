# FULL DE REFERÈNCIA — ANTINIEBLES

## QUAN S'USA CADA LLUM?

### Antiniebla DAVANT (baixa)
| Situació | S'usa? |
|----------|--------|
| Niebla espessa | ✅ SÍ |
| Niebla lleugera | ✅ SÍ (només si cal) |
| Neu (lleugera o intensa) | ✅ SÍ |
| Pluja intensa | ✅ SÍ |
| Vies estreches (≤6,5m) + corbes perilloses | ✅ SÍ (de nit) |
| Fum, pols | ✅ SÍ |
| Carretera seca i clara | ❌ NO |

### Antiniebla DARRERE (roja intensa)
| Situació | S'usa? |
|----------|--------|
| Niebla espessa (visibilitat <50m) | ✅ SÍ |
| Niebla lleugera | ❌ NO |
| Neu lleugera | ❌ NO (encega) |
| Neu intensa | ✅ SÍ |
| Pluja molt intensa | ✅ SÍ |
| Vies estreches (≤6,5m) + corbes perilloses | ✅ SÍ (de nit) |
| Fum/pols dens | ✅ SÍ |

## LA CLAU: DAVANT vs DARRERE

| Llum | Per què | Quan NO |
|------|---------|---------|
| **DAVANT** | Il·lumina el camí, llum àmpla i baixa | Mai a carretera seca i clara |
| **DARRERE** | Fa visible el vehicle per darrere | Encega! Només quan MOLT baixa visibilitat |

## MNEMOTÈCNIC

**Davant = sempre que hi hagi poca visibilitat.**
**Darrere = NOMÉS quan la visibilitat és MOLT dolenta (<50m) o vies estretes.**

## AMB QUINES ALTRES LLUMS ES COMBINA?

| Condicions | Llums obligatòries |
|------------|---------------------|
| Niebla | Cruce + antiniebla trasera |
| Niebla espessa | Cruce + antiniebla trasera + antiniebla delantera |
| Pluja intensa | Cruce o carretera + antiniebla trasera |
| Neu | Cruce + antiniebla delantera (darrere NO amb neu lleugera) |
| **NUNCA** | Luces de carretera (largas) amb niebla |

## ERRORS MÉS FREQUENTS

| Error | Realitat |
|-------|----------|
| "Amb neu no es pot usar antiniebla" | SÍ, la delantera. La darrere NO amb neu lleugera |
| "Antiniebla = només niebla" | També neu, pluja, vies estretes, fum |
| "Davant i darrere sempre juntes" | NO. La darrere és més restrictiva |
| "Vies estretes → només davant" | També DARRERE si tenen corbes perilloses |
