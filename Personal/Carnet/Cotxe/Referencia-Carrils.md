# FULL DE REFERÈNCIA — CARRILS

## PER QUIN CARRIL CIRCULO?

### Via de 2 carrils per sentit
| Carril | Ús | Quan? |
|--------|-----|-------|
| **Dreta** | Circular | SEMPRE (per defecte) |
| **Esquerra** | Adelantar | Només per avançar. Després tornar a la dreta |

### Via de 3 carrils per sentit
| Carril | Ús | Quan? |
|--------|-----|-------|
| **Dreta** | Circular | SEMPRE (per defecte) |
| **Mig** | Circular | Quan el de la dreta està ocupat |
| **Esquerra** | Adelantar + Circular | Quan els altres estan ocupats + no entorpeixes |

### Autopista (més de 3 carrils)
- **Mateixa regla** que via de 3 carrils
- Dreta = circular. Mig = quan ocupat. Esquerra = avançar + circular si cal

## CARRILS ESPECIALS

| Carril | Qui pot usar-lo | Restriccions |
|--------|-----------------|--------------|
| **VAO** | Turismes sols, motos soles, autobusos, emergències, taxis | NO camions, NO furgonetes, NO cotxe+remolc |
| **Bus** | Autobusos | Línia discontinua = entrada/sortida. Línia continua = prohibits |
| **Adicional circunstancial** | Tots | Velocitat: 60-80 km/h. Arcén o calçada lateral |
| **Sentit contrari (obres)** | Tots autoritzats en la via | Senyalització groga |
| **Sentit contrari (fluidez)** | Només turismes sols + motos | NO camions, NO furgonetes |

## REGLA D'OR

**SEMPE per la dreta.** Per l'esquerra NOMÉS quan:
1. Estàs avançant
2. Els altres carrils estan ocupats
3. No entorpeixes els vehicles de darrere

## ERRORS MÉS FREQUENTS

| Error | Realitat |
|-------|----------|
| "Esquerra = només adelantar" | A 3 carrils, també es pot circular si els altres estan plens |
| "VAO = qualsevol cotxe" | NO: només sols (sense remolc, sense furgoneta) |
| "Carril bus = prohibits sempre" | Línia discontinua = sí es pot entrar/sortir |
| "Mig = adelantar" | No, el mig és per circular quan el de la dreta està ocupat |
