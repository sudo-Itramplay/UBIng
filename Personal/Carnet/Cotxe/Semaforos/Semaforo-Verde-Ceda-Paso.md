# Semáforo verde + Ceda el paso — ¿Cuál manda?

## Pregunta de examen (errada)

> El vehículo de la imagen, ¿puede continuar la marcha? (Semáforo verde + señal de ceda el paso)
>
> Respuesta errónea: B) Sí, pero sólo si no hay vehículos cerca.

## Respuesta correcta

**C) Sí, porque el semáforo está verde.**

## Explicación detallada

### Jerarquía de señales: Semáforo > Señal vertical

| Señal | ¿Prioridad? |
|-------|------------|
| **Semáforo en funcionamiento** | **MÁXIMA** — siempre manda |
| Señal de ceda el paso | Se aplica SOLO cuando el semáforo no funciona |
| Señal de stop | Se aplica SOLO cuando el semáforo no funciona |

### ¿Por qué el semáforo verde anula el ceda?

1. El semáforo es una **señal luminosa** (Art. 146 RGC).
2. Las señales luminosas tienen **máxima jerarquía** en el sistema de señalización.
3. El ceda el paso es una **señal de prioridad** que se aplica cuando no hay semáforo.

### ¿Cuándo se obedece el ceda el paso?

- Cuando el semáforo está **apagado** (avería).
- Cuando el semáforo está en **ámbar intermitente** (precaución).
- Cuando no hay semáforo en la intersección.

### ¿Y si el semáforo está en rojo?

- Entonces **te paras**, aunque haya un ceda el paso.
- El semáforo manda siempre: verde = pasas, rojo = paras.

## Recordatorio

**Semáforo encendido = manda el semáforo. Ceda el paso = solo cuando el semáforo no funciona.**
