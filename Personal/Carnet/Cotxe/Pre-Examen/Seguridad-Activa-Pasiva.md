# Seguridad activa vs. pasiva — Tipos de sistemas

## Pregunta de examen (errada)

> 5. Los sistemas de seguridad activa incluyen...
> A) frenos, neumáticos, carrocería, airbags y cinturones de seguridad.
> B) alumbrado, neumáticos, frenos, suspensión y dirección.
> C) chasis, carrocería, cinturones de seguridad, airbags, reposacabezas y casco.

## Respuesta correcta

**VERDAD — Respuesta B.** Los sistemas de seguridad activa son los que **AYUDAN A PREVENIR** el accidente.

## La regla de oro

```
SEGURIDAD ACTIVA  →  PREVIENE el accidente  →  "Evito que pase"
SEGURIDAD PASIVA  →  PROTEGE durante el accidente  →  "Si ya pasó, me protejo"
```

## Seguridad ACTIVA (previene el accidente)

| Sistema | Función |
|---|---|
| **Frenos** (ABS, EBD) | Detener el vehículo |
| **Dirección** | Controlar la trayectoria |
| **Neumáticos** | Adherencia al firme |
| **Alumbrado** | Ver y ser visto |
| **Suspensión** | Estabilidad y contacto con el firme |
| **Retrovisores** | Visibilidad |
| **Parabrisas / limpiaparabrisas** | Visibilidad |
| **Cinturones** (pretensores) | Aunque son pasivos, los pretensores son activos |
| **Control de tracción (TCS)** | Evita patinaje |
| **Control de estabilidad (ESC)** | Evita derrapajes |
| **Airbags** (en algunos contextos) | Se consideran activos cuando actúan PREVIO al impacto |

**Truco:** Todo lo que te ayuda a **CONDUCE** mejor = seguridad activa.

## Seguridad PASIVA (protege durante el accidente)

| Sistema | Función |
|---|---|
| **Cinturones de seguridad** | Mantener al ocupante sujeto |
| **Airbags** | Amortiguar el impacto |
| **Chasis deformable** | Absorber energía del impacto |
| **Carrocería** | Estructura de protección |
| **Reposacabezas** | Prevenir esguince cervical |
| **Casco** | Proteger la cabeza |
| **Airbags laterales** | Protección lateral |
| **Columna de dirección abatible** | Evitar lesiones en el impacto |

**Truco:** Todo lo que **PROTEGE** si ya estás en el accidente = seguridad pasiva.

## Quadre comparatiu ràpid

| Concepte | Activa (PREVIENE) | Pasiva (PROTEGE) |
|---|---|---|
| **Pregunta clau** | "Evito que passi?" | "Si ja ha passat, em protegeixo?" |
| **Exemples** | Frenos, dirección, neumáticos, alumbrado, suspensión | Airbags, cinturones, casco, chasis, reposacabezas |
| **Moment** | ANTES del accidente | DURANTE el accidente |
| **Error típic** | Confundir cinturones con activa (son pasivos) | Confundir ABS con pasivo (es activo) |

## Errores habituales

| Error | Corrección |
|---|---|
| Cinturones = seguridad activa | NO, cinturones = **PASIVA** (protegen durante impacto) |
| Airbags = seguridad activa | NO, airbags = **PASIVA** (se inflan durante impacto) |
| ABS = seguridad pasiva | NO, ABS = **ACTIVA** (ayuda a frenar sin bloquear) |
| Chasis deformable = activa | NO, chasis = **PASIVA** (absorbe energía en impacto) |
| Neumáticos = pasiva | NO, neumáticos = **ACTIVA** (dan adherencia) |

## Recordatorio

**ACTIVA = FRENOS + DIRECCIÓN + NEUMÁTICOS + LUZ + SUSPENSIÓN = PREVIENE.
PASIVA = AIRBAGS + CINTURONES + CASCO + CHASIS + REPOSACABEZAS = PROTEGE.**
