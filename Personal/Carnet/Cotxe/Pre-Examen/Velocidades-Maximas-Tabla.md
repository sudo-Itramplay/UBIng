# Velocidades máximas — Tabla resumen (Art. 48 RGC)

## Fuente: Art. 48 del Reglamento General de Circulación (vigente 2026)

## Tabla principal (fuera de poblado)

| Tipo de vehículo | Autopista / Autovía | Carretera convencional |
|---|:---:|:---:|
| **Turismos, motos, autocaravanas ≤3500 kg, pick-up** | **120** | **90** |
| **Autobuses, derivados de turismo, mixtos adaptables** | **100** | **90** |
| **Camiones >3500 kg, tractocamiones, furgonetas >3500 kg, articulados, con remolque** | **90** | **80** |
| **Ciclos, ciclomotores, cuadriciclos ligeros** | **45** | **45** |
| **Veh. especiales (sin frenado / con remolque / motocultores)** | **25** | **25** |
| **Veh. especiales (resto)** | **40** (70 si >60 en llano) | **40** (70 si >60 en llano) |
| **Sin pavimentar** | **30** | **30** |

## Reducciones especiales

| Concepto | Reducción |
|---|---|
| Transporte escolar / de menores | **-10 km/h** sobre los límites del grupo |
| Mercancías peligrosas | **-10 km/h** sobre los límites del grupo |
| Autobús sin cinturón o con pasajeros de pie | **80 km/h** máx. en cualquier vía interurbana |
| Moto con remolque | **-10%** sobre límites generales |
| Vehículos régimen transporte especial | Según Anexo III RGC |

## Velocidades mínimas (Art. 49 RGC)

| Tipo de vía | Velocidad mínima |
|---|---|
| Autopista / Autovía | **60 km/h** (la mitad de 120) |
| Carretera convencional | **45 km/h** (la mitad de 90) |

## Dentro de poblado

| Zona | Velocidad máxima |
|---|---|
| **General urbana** | **50 km/h** |
| **Zona residencial / escuelas / zona peatonal** | **30 km/h** |
| **Calzada de un solo carril en ambos sentidos** | **30 km/h** (desde reforma 2019) |
| **Calzada con carril bici o ciclista** | **30 km/h** (si no hay acera separada) |

## Recordatorio rápido

```
AUTOPISTA: 120 / 100 / 90  (turismo / bus / camión)
AUTOVÍA:   120 / 100 / 90
CONVENCIONAL: 90 / 90 / 80  (turismo / bus / camión)
URBANA:    50 (general) / 30 (residencial)
CICLO:     45
TRCTOR:    25
```
